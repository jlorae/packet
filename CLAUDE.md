# jlorae/packet — the packet website

This repo is the public home of Jessica's daily packet: the passphrase-locked page her phone opens.
The public part is the app shell and the icons. The packet itself only ever arrives here as a
locked file. Talk to Jessica using the plain-talk skill (stop-slop): lead with the outcome, her
words for things, no jargon.

## The rules

1. **Built output is never committed by a person; the robot publishes it.** `index.html` and
   `desk/index.html` are built on Jessica's computer and pushed by the morning job. Do not edit
   them, do not hand-commit them. *Honest note, 2026-09-07: the robot still publishes by
   committing `index.html` here every morning. That stops when publishing moves to a Pages
   artifact (planned; DAILY-PLAN A9 on her computer). Until then that one file is the exception
   to rule 2, and the pre-commit hook exempts it by name.*
2. **No file over 1 MB. No dry-runs. No zips of things already loose.** `.gitignore` blocks
   dry-run builds and zips; `.githooks/pre-commit` refuses any staged file over 1 MB
   (`git config core.hooksPath .githooks` once per clone).
3. **Every photo has exactly one home.** Graphics live in one folder per campaign, named by date
   and campaign: `graphics/2026-07-15-launch/`. Never a second copy under another prefix, never
   a zip beside the loose files.
4. **Every change to how the app behaves gets a dated note in the decisions log** — who asked
   and why. **The log is not in this repo and must not be duplicated here.** It is Jessica's
   existing, append-only `decisions/log.md` in the AIOS project on her computer
   (`C:\AIOS_Zyia\decisions\log.md`; that project is private and never public). Dated
   decision comments used to live inside the app shell; they were moved into that log on
   2026-09-07 and must not come back.
5. **Settings such as web addresses live in one config file, never typed into the app by
   hand.** The app is generated by `build_packet_app.py` (in the private `packet-build` repo);
   addresses and IDs it needs come from `config`-style files it reads, not from string edits
   inside the built page.
6. **Commit messages say what changed, not the date.** Git already knows the date.
7. **Talk to Jessica with the plain-talk skill.** Outcome first, mechanism second, her names for
   things.

## What lives where

- `index.html`, `desk/index.html` — built output (see rule 1).
- `manifest.webmanifest`, `sw.js`, icons, `landing*.jpg`, `logo.jpg` — the app shell.
- `graphics/<yyyy-mm-dd>-<campaign>/` — the campaign photos the packet links to (rule 3).
- The code that builds all of this: private repo `jlorae/packet-build`.
